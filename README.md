# 五子棋 · 控制台版

纯 Python 标准库实现的终端五子棋，支持**局域网联机**、本地双人、人机对战，
带悔棋、投降、重开、比分与对局回放。

无第三方依赖，不需要 pip install。

## 环境

- Python 3.9+（开发环境 3.13）
- Windows / Linux / macOS 的终端（Windows 推荐 Windows Terminal 或 cmd）

## 运行

```bash
python main.py            # 默认端口 9527
python main.py --port 9600
```

Windows 下也可以双击 `run.bat`。

> 请在 **cmd / Windows Terminal / PowerShell 窗口**里运行。Git Bash 的 mintty、
> 部分 IDE 内置终端对逐键读取支持不好，会出现按键无反应。需要重新开启 VT 时
> 在终端属性里勾选「使用旧版控制台」以外保持默认即可。

## 三种模式

| 模式 | 说明 |
|---|---|
| 创建房间（主机） | 监听端口，界面会显示本机 IP，等待对手接入 |
| 加入房间 | 自动扫描局域网房间，扫描不到可手动输入 IP |
| 本地双人 | 同一台机器轮流落子 |
| 人机对战 | 与内置启发式 AI 对下 |

### 局域网联机步骤

1. 两台机器连同一个 Wi-Fi / 交换机。
2. A 机器选「创建房间」，记下界面显示的 `192.168.x.x:9527`。
3. B 机器选「加入房间」，等待约 2.5 秒扫描，选中房间回车；或手动输入 IP。
4. 双方自动握手，房主执黑先行。

**连不上先查防火墙**：Windows 首次运行会弹「允许访问网络」，务必勾选专用网络。
如果错过了，手动放行 `python.exe` 的入站规则，或临时关闭防火墙测试：

```powershell
New-NetFirewallRule -DisplayName "Gomoku" -Direction Inbound -Program "C:\Path\To\python.exe" -Action Allow
```

端口占用时换端口：`python main.py --port 9600`，双方端口一致或加入方手动填写。

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 | 移动光标 |
| 空格 / 回车 | 落子 |
| U | 悔棋（需对方同意，每人每局 3 次） |
| R | 重新开始（需对方同意，交换先后手） |
| Q | 投降（本地二次确认） |
| Y / N | 应答对方的悔棋、重开请求 |
| Esc | 离开对局 / 返回菜单 |

## 规则说明

- 15×15 棋盘，黑先，横竖斜任意方向连成 5 子（含长连）即胜，无禁手。
- **悔棋**：请求方发起，对方确认后才生效。回滚到「轮到请求方落子」的最近局面，
  也就是会连带撤回对方的那一手。每人每局上限 3 次，被拒后需自己走完一手才能再次申请。
- **投降**：本地确认后立即生效，对方记一胜。
- **重开**：双方同意后清盘，交换执黑/执白，比分保留，悔棋次数重置。
- 断线：1 秒心跳，超过 8 秒无数据判定断线，本局记为未分胜负。

## 协议

TCP 长连接，换行分隔的 JSON：

```json
{"t":"move","d":{"x":7,"y":7},"g":1,"s":12}
```

| 类型 | 方向 | 作用 |
|---|---|---|
| `hello` | 双向 | 握手，交换名字 |
| `start` | 主机→加入方 | 开局，指定黑白双方 |
| `move` | 双向 | 落子坐标 |
| `undo_req` | 双向 | 悔棋请求（带目标手数） |
| `undo_ack` | 双向 | 悔棋应答（同意/拒绝+原因） |
| `resign` | 双向 | 投降 |
| `restart_req` / `restart_ack` | 双向 | 重开协商 |
| `ping` / `pong` | 双向 | 心跳 |
| `bye` | 双向 | 主动离开 |
| `error` | 双向 | 协议错误提示 |

悔棋的目标局面由「请求方颜色 + 当前手数」唯一确定，双方各自本地计算，
不需要传输棋盘，因此不会出现两端不一致。非法或越权消息只提示并忽略，不会崩溃。

房间发现用 UDP：主机每秒向 `255.255.255.255:9528` 广播一次房间信息，
加入方在 9528 上收 2.5 秒后列出房间。

## 目录结构

```
Gomoku/
  main.py            入口与命令行参数
  selftest.py        规则/协议/AI 自检（31 项）
  selftest_net.py    联机流程自检（20 项，真实 TCP）
  run.bat            Windows 一键启动
  gomoku/
    board.py         棋盘、落子合法性、五连检测
    session.py       对局状态机、计分、回放导出
    ai.py            启发式 AI
    protocol.py      JSON 行协议编解码
    net.py           TCP 监听/连接、读线程、心跳
    discovery.py     UDP 房间发现
    terminal.py      VT 开启、非阻塞按键
    render.py        棋盘绘制
    app.py           菜单、事件循环、三种模式与协商流程
  replays/           对局回放（结束后自动生成）
```

## 自检

```bash
python selftest.py        # 规则、悔棋一致性、AI、协议、传输、回放
python selftest_net.py    # 两个实例真实 TCP 对局：落子/悔棋/重开/投降/断线
```

## 已知限制

- 只有两名玩家，无观战与聊天。
- AI 是一层搜索的启发式，能挡四追三，但不是强引擎。
- 回放是文本格式（落子序列），可以直接照着复盘，暂不支持界面回放。
